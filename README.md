# Home Credit - Credit Risk Model Stability

本项目基于 Kaggle 的 **Home Credit - Credit Risk Model Stability** 竞赛，目标是利用客户申请信息、历史贷款记录及征信等数据，预测客户发生贷款违约的风险。

项目不仅关注模型的预测能力，也关注模型表现随时间变化的稳定性。我们将通过数据分析、特征工程、模型训练与验证，构建长期可靠的信用风险评估方案，为信贷决策提供参考。

竞赛地址：[Home Credit - Credit Risk Model Stability](https://www.kaggle.com/competitions/home-credit-credit-risk-model-stability)
